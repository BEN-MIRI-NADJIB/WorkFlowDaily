# WorkFlow Streamlit

## Streamlit Community Cloud
1. Crée un dépôt GitHub.
2. Mets `app.py` et `requirements.txt` à la racine.
3. Sur Streamlit Community Cloud, crée une app depuis ce dépôt.
4. Choisis `app.py` comme fichier principal.

> Note: `tasks.json` est un stockage fichier simple utile en local. Pour un hébergement persistant multi-session, remplace-le ensuite par une base distante autorisée.
